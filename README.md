# SmartAssess – Computer Aptitude & Skill Assessment System

A web project built with HTML, CSS and JavaScript. Take a timed 20-question test across four
skill areas and get a performance dashboard with charts, skill level and recommendations.

## Files
- `index.html` – page structure
- `style.css` – design (light and dark theme)
- `script.js` – test logic, timer, charts, history

## Run
Open the folder in VS Code, install the **Live Server** extension, right-click `index.html`
and choose **Open with Live Server**. (An internet connection is needed for Chart.js and Google Fonts.)
