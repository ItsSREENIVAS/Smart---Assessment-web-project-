How it works

Choose a full test, a quick test or a single-category practice, pick a time limit, and answer. Use the number buttons to jump between questions, or the keyboard: A–D or 1–4 to answer, arrow keys to move.

Built with

HTML for structure, CSS for the responsive light and dark design, JavaScript for the test logic and local storage, and Chart.js for the charts.
